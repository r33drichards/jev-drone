# X4: observability check

**Setup.** `modal run modal_laya.py::teacher_features`: the teacher flies the six 4x courses x seeds 20-23, logging
per decision (teacher._features) the true observables (rover visible, bearing, range while visible, speed, direction
of travel, altitude, 24 lidar sectors), privileged features (rover position in the drone's frame now and 1, 2, 3 s
ahead, rover velocity) and its choice. `python autoresearch/x4_fit.py`: softmax regression and 15-NN, leave one seed
out, per feature set.

**Predictions** (written before): H5: privileged far better than observable; H1/H4: true observables predict the
turn well above Laya's image-only 35%.

**Result** (`X4-fit.json`; best of softmax / kNN):

| features | turn | speed | slide |
|---|---|---|---|
| majority | 26.9% | 37.8% | 36.9% |
| observable (true) | 44.7% | 59.1% | 69.5% |
| + memory (2 previous decisions) | 46.3% | 60.0% | 69.6% |
| + privileged (future rover positions, velocity) | 45.5% | 60.5% | 71.4% |

**Evidence.** E13. Privileged information adds at most 2 points (strongly against H5). Laya v3.8 from pixels (48%
turn, image-only) already matches a model given the true bearing (against H1). The ceiling near 46% even with
perfect information shows the teacher's choice among near-equal candidates is partly arbitrary: regret, not top-1,
is the yardstick. Caveat: simple models on hand features (medium credibility).
