# X1: train vs deploy input audit

**Setup.** Compared how `teacher.fly(record=True)` / `teacher._sample` recorded the student's inputs with how
`run.episode` (policy `laya-cmd`) and `teacher.diagnose` feed them at flight time.

**Predictions.** H8: a difference appears. Others: identical inputs.

**Result.**
- Same context keys (`command.CMD_KEYS`) in the same order (`laya_pursuit.v3_state`), same `flight.Eye` (512x384
  RGB, same camera), same turn convention (relative to the nose at the decision, flown as an absolute heading).
- Differences: training frames are JPEG q90 (re-encoded), flight frames raw arrays; `prev_speed` / `prev_turn` are
  the TEACHER's previous choice in training and the STUDENT's own previous answer in flight (and 0.25 s old in
  training vs ~0.13 s at 7.6 Hz in flight).
- How much the previous command gives away (teacher_sharp val, 1760 decisions): copying `prev_turn` to the nearest
  turn level matches the teacher's turn 49% (majority level 21%); copying `prev_speed` matches its speed 65%
  (majority 43%); correlations 0.77 and 0.68. The student's overall top-1 is 60%.

**Evidence.** E8. No bug-level mismatch (against H8), but the copycat shortcut is strong: new hypothesis H9.
